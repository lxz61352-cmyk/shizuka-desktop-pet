## （以下均为大肥鱼代笔）

《World Dai Star》静香的 Windows 桌面宠物。她会待在桌面陪着你：聊天、记事、提醒，对复制的内容做出反应，能报天气和新闻，还能播放i wanna（激烈的5k楼梯转仁王盾ing）。

- 平台：**Windows x64**（Windows 11 实测；Windows 10 待测， Mac 版开发中）
- 技术：Python + Tkinter + Pillow，PyInstaller 打包
- 版本：**V0.8.1**
- 本仓库同时提供**免装 Python 的打包版**（`Shizuka.exe` + `_internal/`）和**完整源码**（`src/`）。

## 功能特性

- **聊天**：任意 OpenAI 兼容接口（默认 DeepSeek），流式气泡显示；填自己的 API Key 即可。DeepSeek 官方接口下各种模型名会统一到同一个（v0.8.1），不用再纠结填哪个。
- **记忆**：显式「记住…」+ 模型自动提取长期信息，按相关度注入；对话统一近期上下文（最多 100 条 / 48000 字），并定期提炼带来源的长期事实与主题索引。
- **待办 / 提醒**：直接说「提醒我明天 9 点开会」就能记下，也能用 `/待办` 一次整理多条；分「生活 / 研究」，支持提前提醒、周期提醒，桌面 + 微信双通道。
- **剪贴板**：中文反应、外语翻译、图片/截图识别、网页正文概括。
- **天气 / 新闻**：问「今天天气怎么样」「讲个新闻听听」；天气按网络环境自动在国内外两个源之间选，开机问候也会结合真实天气。
- **电脑助手**：`/电脑 读取…` 由本机 DSH 执行文件任务，过程窗口只读，确认问题在聊天里回答。窗口里可以选「任务模型」（跟随聊天 / 视觉模型 / 继承 DSH 默认）；带图片的任务会自动改用视觉模型，失败时会在 `data/computer-tasks/` 留下日志。
- **微信**：扫码绑定后可远程对话、识图、发文件任务（需自备账号）。发图后可以用「图三」这样的说法指定某张，没说图时会自动带上最近发的图。
- **研究进展（开发中）**：按自己配置的研究方向筛文献的功能还没做完，暂时没开放。
- **开机问候**：按概率说天气 / 闲聊（天气取不到就只打招呼）。
- **主动发言**：在有具体内容时开口（具体观察、实用提醒、相关小知识）。
- **角色包**：静香 · 微动版（同一张立绘上的轻微差分/微动）。
- **鼠标互动**：左键摸头、右键提起放下、双击跳、滚轮缩放、空闲打盹、落在窗口上（试验）。
- **背景音乐「i wanna」**：菜单播放，齿轮下方出现旋转唱片，单击暂停/继续、长按 3 秒结束。
- **语音朗读（可选）**：本地 GPT-SoVITS，**启动时自动检测**；没装则菜单提示、不影响其他功能。
- **使用时长**：记录各程序的使用时长，问「我今天用了多久」会直接汇报。
- **检查更新**：自动查 GitHub Release，直连不通自动走镜像；更新重启后弹一次更新公告。
- **多显示器**：待办、对话记录、微信、电脑助手等窗口都会跟着桌宠出现在它所在的那块屏幕上（v0.8.1），不会跑到主屏、也不会先闪一下。

## 一、第一次使用（安装）

1. 把仓库/ZIP **完整解压**到一个自己能写入的文件夹（例如 `D:\静香桌宠`）。
   **不要只把 `Shizuka.exe` 单独拿出来**——旁边的 `_internal`、`assets`、`characters` 文件夹都要一起保留，缺一个会打不开或没声音。
2. 双击 **`Shizuka.exe`**（或 `启动桌宠.bat`）。这个包自带运行环境，**不需要安装 Python**。
3. 第一次打开只有动作和问候，还不会聊天。点**齿轮 →「模型与接口」**，填入你自己的 Key（DeepSeek，或任意 OpenAI 兼容接口），保存后会**自动识别服务商**并连上。
   Key 存进 **Windows 凭据管理器**（系统加密、绑定当前用户），**程序目录里不会留下 Key 文件**；没有 Key 也能看动作，只是不聊天。
4. 只想看动作、不接聊天：运行 `预览动作.bat`。
5. 想开机自动启动：齿轮 →「更多设置 ›」→「开机自动启动」；或者给 `Shizuka.exe` 建个快捷方式，放进 `Win+R` → `shell:startup` 打开的文件夹。

- 你的聊天、记忆、待办、设置都保存在解压目录的 `data/` 里。换电脑或升级前先备份；**转发给别人时，别把自己的 `data/` 一起发出去。**
- 源码运行：装好含 Tcl/Tk 的 Python（3.10~3.13）后 `pip install -r src/requirements.txt`，再运行 `源码启动.bat`（或 `python src/run_pet.py`）。

## 二、鼠标怎么用

| 操作 | 效果 |
| --- | --- |
| 左键单击 | 打开/收起聊天输入框（为区分双击会等约 0.25 秒） |
| 左键双击 | 连跳两次 |
| 左键按住头顶，横向拖动 | 抚摸，头部和发梢轻轻响应 |
| 右键按住拖动 | 把桌宠提起来，松手落回任务栏上沿 |
| 右键轻点 | 打开/关闭余额气泡 |
| 滚轮 | 缩放桌宠（130–520px） |
| 隐藏 | 菜单中选择“隐藏到托盘”，或将静香拖动到屏幕边框进行隐藏（进入越共探头模式），此时无法进行各种功能（待办只会有提示音而不会触发对话），tts语音服务也会静默，不占用资源，再次点击即可唤醒 |

电脑和桌宠空闲 1 分钟会短暂打盹（zzz）；再次操作就醒来。隐藏满 30 秒再叫出会跳两下。聊天、下落或正在操作窗口时暂停自动动作。齿轮 →「更多设置 ›」→「自动小动作」可关掉这些自动行为。

## 三、聊天与记忆

- 单击角色打开输入框，输入后回车发送；回复以**流式气泡**显示（默认约 20 字/秒），可随时单击角色打断。
- **记忆**：说「记住…」会存成永久记忆；平时模型也会自己判断值得长期记住的信息（习惯、喜好、长期目标等）存下来，并尽量保留你的原话来源。齿轮 →「查看记忆」可查看/编辑/删除。
- **近期上下文**：最近 100 条 / 48000 字以内的对话会一起带上；更早的历史完整保留在 `data/对话记录/`，并定期提炼成长期事实与主题索引（不再需要手动调「对话记忆条数」）。
- **待办**：直接说「提醒我明天 9 点开会」「2 小时后给妈妈打电话」；也可以用 `/待办 明天上午9点阅读论文` 一次整理多条（自动分生活/研究、拆备注、算提前量）。时间模糊时她会追问；到点弹气泡 + 提示音，桌面和微信都会提醒。
- **天气 / 新闻**：问「今天天气怎么样」「要带伞吗」「讲个新闻听听」。天气会按你的网络环境自动选源（能直连外网时用 Open-Meteo，否则用中央气象台），两边都取不到会直说，不会瞎编。
- **开机问候 / 待办提醒**：启动时按概率说一句天气 / 闲聊；未完成的待办会挑重点提醒。可在齿轮 →「更多设置 ›」里关掉。
- （来自作者）记忆系统和上下文会被携带进入下一轮的对话中，因此静香有可能受到前文的影响，以同一种口吻说话。此问题暂时以增加约束性提示词的方式修复，如果在使用中还是高强度地出现同一种说话模式，如解析网页链接和截图时一直以“啊，这不是xxx吗”起手的话，请及时反馈问题，或者使用自己的agent尝试解决问题后将问题描述和使用的修复方案一同上传到issue中，以进行更细致的调整。

## 五、语音朗读（可选）

桌宠可以用本地 **GPT-SoVITS** 把话念出来（文字跟着朗读速度出）。

- **自动检测**：启动时会在本机自动寻找 GPT-SoVITS。装了的话，齿轮 →「更多设置 ›」里的「**语音朗读**」就是个开关，打开即可；参考音色（`assets/voice_ref1.wav`）已经随包带好，**不用自己再找音色**。
- **没装的话**：那一栏会显示「**未检测到 gpt-sovits，语音功能暂时无法使用**」，点一下可以手动指定 GPT-SoVITS 文件夹；**完全不影响聊天等其他功能**。
- GPT-SoVITS 安装包比较大（十几个 GB，需要 NVIDIA 显卡），不随仓库提供，请自行安装；不想用可以完全不管它。
- 第一次打开语音要加载约 30~60 秒，期间显示「语音服务加载中…」；隐藏桌宠时可按「语音服务释放」策略释放显存。

### 音色模型（`voice_model/`）

`voice_model/` 里放着一对训练好的**喜多郁代**音色模型（GPT-SoVITS 的 `.ckpt` + `.pth`，约 328MB），用法与来历见 [`voice_model/说明.md`](voice_model/说明.md)。

简单说：没有专门训练静香的声音，直接用了现成的喜多郁代音色——因为静香和喜多郁代**都是长谷川育美配音**，音色接近。

### 关于 Git LFS

两个模型文件都超过 GitHub 单文件 100MB 上限，走的是 **Git LFS**：

- 用 `git clone` 时请先装 [Git LFS](https://git-lfs.com/)，否则只会拿到指针文件；
- 在网页点 **Download ZIP 不会包含** LFS 大文件；
- 想直接下载完整包，可在仓库的 **Releases** 里取打包好的压缩包。

## 七、剪贴板

开启「检测剪贴板」后，每 1.5 秒看一次剪贴板，只对**新复制**的内容反应：

- **中文** → 说一句简短反应。
- **外语**（英/日/韩等，开关「翻译剪贴板」默认开）→ 翻译成中文 + 一句反应。
- **图片 / 截图** → 识别图里内容，用她的口吻说一句（图里是心菜会认出来）。
- **网址** → 抓取网页正文，概括给你听。
- **图片文件路径** → 按图片识别。

**同一段内容只会回应一次**：复制同一段（或者把选区慢慢加长）不会再重复点评，等内容换了才说话；同一张图也不会反复点评。剪贴板内容**只做反应，不会被当成指令**去设待办。桌宠折叠时不会说话。

## 八、待办 / 电脑助手 / 微信 / 研究进展 / 记忆同步

- **待办**：齿轮 →「待办」，或点角色右侧的待办按钮。可以直接说自然语言，也可以在窗口里写「明天9点」后确认解析。每条待办可以设提醒时间、提前量、周期（每天/每周/工作日）、生活或研究分类，桌面和微信各自决定要不要提醒。
- **电脑助手**：齿轮 →「电脑助手」，或在聊天里说「/电脑 把桌面上的笔记整理成 Markdown」。任务由本机已装的 **DSH** 执行（需要 Node.js 和 dsharness，并用你自己的模型账户），执行过程是一个只读窗口，需要确认的问题会回到聊天里问你。可以设置文件操作范围（仅工作文件夹 / 当前账户可访问）。
- **微信**：齿轮 →「微信连接」，扫码绑定后可远程和静香对话、发图识图、下文件任务、收待办提醒。需自备账号，本仓库不含任何人的配对或聊天数据。
- **研究进展（开发中）**：齿轮 →「研究进展（开发中）」。这个功能还没完全做好，先没开放（菜单点了会提示"还在开发中"）。
- **记忆同步**：齿轮 →「双端共享记忆」配置配对，「立即同步记忆」手动同步一次。当前共享的是记忆、聊天和待办核心字段，备注/周期规则/通知状态仍是本机旁表（详见 `AI-DEVELOPMENT.md`）。

## 九、隐藏 / 折叠 / 按钮 / 菜单

- **拖到屏幕左右边缘外**会自动折叠，只露出半个斜着的脑袋；单击那半个脑袋唤回。菜单「隐藏到托盘」也可收起。
- 角色脚边竖排三个按钮：**待办 / 对话 / 齿轮**（贴角色右侧、随缩放变化）：
  - **待办**：查看/编辑待办，可写自然语言时间（如「明天9点」）后点确认解析。
  - **对话**：查看历史对话（静香蓝框、你白框），持久化在 `data/characters/<角色>/对话记录/`。
  - **齿轮**：打开菜单。
- 菜单（点齿轮打开）从上到下分几组：
  1. **音乐**：播放 i wanna / 暂停 / 继续 / 结束
  2. **日常**：待办、更多设置 ›
     - **更多设置 ›**（悬停展开）：提示音、测试提示音、显示速度、语音朗读、配置语音（GPT-SoVITS）…、语音服务释放、主动搭话间隔、检测剪贴板、翻译剪贴板、开机问候、开机待办提醒、记录窗口使用时长、角色动态、自动小动作、落在窗口上、开机自动启动
  3. **助手能力**：电脑助手、微信连接、研究进展（开发中）
  4. **记录与记忆**：窗口时长统计、查看记忆、双端共享记忆、立即同步记忆
  5. **接口与维护**：模型与接口、查询余额、检查更新（v0.8.1）
     - 「检查更新」左键检查/更新，**右键**可以停止或重新接收更新
  6. **系统**：隐藏到托盘、关闭
