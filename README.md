# 静香桌宠（Shizuka DeskPet）

《World Dai Star》静香的 Windows 桌面宠物。她会待在桌面左下角陪着你：聊天、记事、提醒，对复制的内容做出反应，还能播放i wanna。

- 平台：**Windows x64**（Windows 11 实测；Windows 10 待测，不提供 Mac 版）
- 技术：Python + Tkinter + Pillow，PyInstaller 打包
- 版本：**V0.6.0**
- 本仓库同时提供**免装 Python 的打包版**（`Shizuka.exe` + `_internal/`）和**完整源码**（`src/`）。

---

## 功能特性

- **聊天**：任意 OpenAI 兼容接口（默认 DeepSeek），流式气泡显示；填自己的 API Key 即可。
- **记忆**：显式「记住…」+ 模型自动提取长期信息，按相关度注入。
- **待办 / 提醒**：自然语言解析时间，到点弹气泡 + 提示音；可查看/编辑。
- **剪贴板**：中文反应、外语翻译、图片/截图识别、网页正文概括。
- **开机问候**：按概率说天气 / 前台窗口 / 闲聊 / 新闻。
- **角色包**：静香 · 微动版（同一张立绘上的轻微差分/微动）与 单图版，可切换。
- **鼠标互动**：左键摸头、右键提起放下、双击跳、滚轮缩放、空闲打盹、落在窗口上（试验）。
- **背景音乐「i wanna」**：菜单播放，齿轮下方出现旋转唱片，单击暂停/继续、长按 3 秒结束。
- **语音朗读（可选）**：本地 GPT-SoVITS，**启动时自动检测**；没装则菜单提示、不影响其他功能。

## 一、第一次使用（安装）

1. 把仓库/ZIP **完整解压**到一个自己能写入的文件夹（例如 `D:\静香桌宠`）。
   **不要只把 `Shizuka.exe` 单独拿出来**——旁边的 `_internal`、`assets`、`characters` 文件夹都要一起保留，缺一个会打不开或没声音。
2. 双击 **`Shizuka.exe`**（或 `启动桌宠.bat`）。这个包自带运行环境，**不需要安装 Python**。
3. 第一次打开只有动作和问候，还不会聊天。点**齿轮 → 设置 API Key**，填入你自己的 Key（DeepSeek，或任意 OpenAI 兼容接口），保存后会**自动识别服务商**并连上。
   Key 用 Windows 加密保存在 `api_key.txt`，文件里看不到明文；没有 Key 也能看动作，只是不聊天。
4. 只想看动作、不接聊天：运行 `预览动作.bat`。
5. 想开机自动启动：给 `Shizuka.exe` 建个快捷方式，放进 `Win+R` → `shell:startup` 打开的文件夹。

- 你的聊天、记忆、待办、设置都保存在解压目录的 `data/` 里。换电脑或升级前先备份；**转发给别人时，别把自己的 `data/` 和 `api_key.txt` 一起发出去。**
- 源码运行：装好含 Tcl/Tk 的 Python（3.10~3.13）后 `pip install -r src/requirements.txt`，再运行 `源码启动.bat`（或 `python src/run_pet.py`）。

## 二、鼠标怎么用

| 操作 | 效果 |
| --- | --- |
| 左键单击 | 打开/收起聊天输入框（为区分双击会等约 0.25 秒） |
| 左键双击 | 连跳两次 |
| 左键按住头顶，横向拖动 | 抚摸，头部和发梢轻轻响应 |
| 右键按住拖动 | 把桌宠提起来，松手落回任务栏上沿 |
| 右键轻点 | 打开/关闭余额气泡 |
| 滚轮 | 缩放桌宠（130–520px） |

电脑和桌宠空闲 1 分钟会短暂打盹（zzz）；再次操作就醒来。隐藏满 30 秒再叫出会跳两下。聊天、下落或正在操作窗口时暂停自动动作。齿轮 →「自动小动作」可关掉这些自动行为。

## 三、聊天与记忆

- 单击角色打开输入框，输入后回车发送；回复以**流式气泡**显示（默认约 20 字/秒），可随时单击角色打断。
- **记忆**：说「记住…」会存成永久记忆；平时模型也会自己判断值得长期记住的信息（习惯、喜好、长期目标等）存下来。问「你记得什么」可以查看。设置菜单 →「查看记忆」可编辑/删除。
- **短期上下文**：默认记住最近 3 轮对话，设置菜单「对话记忆条数」可调（0 关闭）。
- **待办**：说「提醒我明天 9 点开会」「2 小时后给妈妈打电话」等。时间必须明确，模糊时她会追问；到点会弹气泡 + 提示音。点对话/待办按钮可查看记录。
- **开机问候 / 待办提醒**：启动时按概率说一句天气 / 前台窗口 / 闲聊 / 新闻；未完成的待办会挑重点提醒。可在设置菜单关掉。

## 四、提示音

设置菜单 →「提示音」：**所有消息 / 仅待办 / 无**（默认仅待办）。菜单下栏有「测试提示音」可直接试听。

## 五、语音朗读（可选）

桌宠可以用本地 **GPT-SoVITS** 把话念出来（文字跟着朗读速度出）。

- **自动检测**：启动时会在本机自动寻找 GPT-SoVITS。装了的话，设置菜单里的「**语音朗读**」就是个开关，打开即可；参考音色（`assets/voice_ref1.wav`）已经随包带好，**不用自己再找音色**。
- **没装的话**：设置菜单那一栏会显示「**未检测到 gpt-sovits，语音功能暂时无法使用**」，点一下可以手动指定 GPT-SoVITS 文件夹；**完全不影响聊天等其他功能**。
- GPT-SoVITS 安装包比较大（十几个 GB，需要 NVIDIA 显卡），不随仓库提供，请自行安装；不想用可以完全不管它。
- 第一次打开语音要加载约 30~60 秒，期间显示「语音服务加载中…」；隐藏桌宠时可按「语音服务释放」策略释放显存。

### 音色模型（`voice_model/`）

`voice_model/` 里放着一对训练好的**喜多郁代**音色模型（GPT-SoVITS 的 `.ckpt` + `.pth`，约 328MB），用法与来历见 [`voice_model/说明.md`](voice_model/说明.md)。

简单说：没有专门训练静香的声音，直接用了现成的喜多郁代音色——因为静香和喜多郁代**都是长谷川育美配音**，音色接近。

### 关于 Git LFS

两个模型文件都超过 GitHub 单文件 100MB 上限，走的是 **Git LFS**：

- 用 `git clone` 时请先装 [Git LFS](https://git-lfs.com/)，否则只会拿到指针文件；
- 在网页点 **Download ZIP 不会包含** LFS 大文件；
- 想直接下载完整包，可在仓库的 **Releases** 里取打包好的压缩包（如有）。

## 六、背景音乐「i wanna」

- 设置菜单 →「**播放 i wanna**」开始播放；歌放在 `assets/i_wanna.mp3`。
- 播放时，齿轮图标**正下方**会出现一张**旋转的唱片**（用歌曲封面裁成的圆形 + 中间挖个孔），和三个按钮一样大、对齐成一列。
- **单击唱片**：暂停 / 继续（暂停时唱片停止旋转）。
- **长按唱片 3 秒**：结束播放（唱片淡出）。
- 播放期间菜单里对应显示「暂停播放 / 结束播放」，暂停后显示「继续播放 / 结束播放」。

## 七、剪贴板

开启「检测剪贴板」后，每 1.5 秒看一次剪贴板，只对**新复制**的内容反应：

- **中文** → 说一句简短反应。
- **外语**（英/日/韩等，开关「翻译剪贴板」默认开）→ 翻译成中文 + 一句反应。
- **图片 / 截图** → 识别图里内容，用她的口吻说一句（图里是心菜会认出来）。
- **网址** → 抓取网页正文，概括给你听。
- **图片文件路径** → 按图片识别。

剪贴板内容**只做反应，不会被当成指令**去设待办。桌宠折叠时不会说话。

## 八、隐藏 / 折叠 / 按钮 / 设置菜单

- **拖到屏幕左右边缘外**会自动折叠，只露出半个斜着的脑袋；单击那半个脑袋唤回。设置菜单「隐藏到托盘」也可收起。
- 角色脚边竖排三个按钮：**待办 / 对话 / 设置**（贴角色右侧、随缩放变化）：
  - **待办**：查看/编辑待办，可写自然语言时间（如「明天9点」）后点确认解析。
  - **对话**：查看历史对话（静香蓝框、你白框），持久化在 `data/对话记录/`。
  - **设置**：打开设置菜单。
- 设置菜单：提示音、功能开关（检测剪贴板 / 翻译剪贴板 / 开机问候 / 开机待办提醒 / 语音朗读 / 角色动态 / 自动小动作 / 落在窗口上）、显示速度、对话记忆条数、播放 i wanna、角色与外观、角色动作、测试提示音、设置 API Key、查看记忆、隐藏到托盘、关闭。

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `Shizuka.exe` + `_internal/` | 打包好的可运行程序（免装 Python） |

| `characters/` | 角色包（静香 · 微动版 / 单图版） |

| `tools/` `tests/` | 构建脚本、回归测试 |
| `references/` `LICENSES/` | 参考资料与第三方许可 |

| `api_key.txt` | API Key（加密存储；仓库里是空文件，填了才会生成内容） |
