## 使用说明（由gpt代写）

这是一个《World Dai Star》静香的 Windows 桌宠。平时可以放在桌面上，和她聊天、记个待办，或者用微信从手机上找她。也塞了一些自己用得上的小功能，比如番茄钟、看图读文件和播放 i wanna。

现在是 **v0.8.17**。想直接用，去 [Releases 下载完整包](https://github.com/lxz61352-cmyk/shizuka-desktop-pet/releases/latest)，解压后打开 `Shizuka.exe` 就行。仓库里的 EXE 也已更新；不要只下载一个 EXE，它需要旁边的文件一起运行。

- 平台：**Windows x64**（Windows 11 实测；Windows 10 待测， Mac 版开发中）

聊天要自己准备模型接口和 API Key，主要用 DeepSeek 测试。其他兼容接口可以尝试，但不保证每一家都适配。语音和电脑文件助手是另外配置的，不用它们也能正常聊天。

[更新公告](更新公告.md) · [源码运行与构建](文档/开发与验证.md) · [反馈问题](https://github.com/lxz61352-cmyk/shizuka-desktop-pet/issues)

## 下载后怎么用

1. 下载 `Shizuka-0.8.17-Windows-x64.zip`，完整解压到自己能写入的目录。
2. 双击 `Shizuka.exe`。不用装 Python，也不要拆开 `_internal`、`assets`、`characters` 等配套文件夹。
3. 打开齿轮菜单里的「模型与接口」，填自己的接口地址、模型和 Key。一般先选 `chat`；`response` 是否可用取决于接口服务商。
4. 想在手机上聊，再打开「微信连接」扫码绑定。电脑和桌宠要保持运行。

旧用户可以在程序里检查更新。手动换包前，先退出旧版并备份 `data`，再把新包解压到原目录覆盖程序文件；不要删除自己的 `data`。如果你用环境变量指定了其他数据目录，继续沿用原设置。

聊天、记忆、待办和个人设置保存在本机。转发程序给别人时，**不要连自己的 `data`、微信附件或备份一起打包**。程序包不附带 API Key、微信绑定、GPT-SoVITS 环境或语音模型权重。

## 桌面上怎么操作

| 操作 | 效果 |
| --- | --- |
| 左键单击 | 打开或收起输入框；正在回复时不会因为普通单击打断朗读 |
| 左键双击 | 平时连跳两次；正在回复时打断并打开输入框 |
| 按住头顶横向拖动 | 摸头 |
| 右键拖动 | 提起，松手放下 |
| 右键轻点 | 打开或关闭余额气泡 |
| 滚轮 | 缩放桌宠 |
| 隐藏 | 菜单中选择“隐藏到托盘”，或将静香拖动到屏幕边框进行隐藏（进入越共探头模式），此时无法进行各种功能（待办只会有提示音而不会触发对话），tts语音服务也会静默，不占用资源，再次点击即可唤醒 |

脚边三个按钮分别是待办、对话记录和齿轮。拖到屏幕左右边缘也能折叠，点露出来的脑袋再叫回来。折叠、隐藏或关闭当前聊天会停止这轮朗读；是否释放语音服务由相应设置决定。

- （来自作者）多显示屏折叠时如果放在两个显示屏中间的接缝处可能会有屏幕另一侧露出一小部分或者探头方向相反，这是系统原因导致的，暂时无法修复。

## 聊天、看图和文件

输入后按 Enter 发送，Shift+Enter 换行。长回复可以滚动、展开和复制，没发出去的文字会保存为草稿。

输入框的「截图」「文件」可以带上材料，也可以直接粘贴图片。「材料」里能预览、调整顺序、移除，或者选回最近用过的附件。PDF 先选页再发，不会把整份文件都塞给模型。

目前聊天能读图片、文本、代码和 PDF。单个文件最多 25MB，一次最多 6 份附件或 PDF 页面；很长的文本会截断并标明。Word、音视频等还没有专门的聊天读取器，微信收到后可以先保存。

回复或聊天记录可以右键标记反馈，再预览、修改并导出。觉得她哪里说得僵、没接上话，把前后几句一起留着，比只截一句更方便排查。

### 记忆

可以明确说「记住……」，平时也会提取值得长期保留的信息。在「查看记忆」里能编辑、删除、查看来源，给临时安排设有效期，或者标成「事情已结束」。误改了可以撤销最近一次。

新开一段聊天不会清空长期记忆。当前对话和相关记忆会一起影响回答，但不是把所有旧事都带进来；完整聊天记录仍会保留。搜索记录后双击结果，可以展开前后文。

- （来自作者）记忆系统和上下文会被携带进入下一轮的对话中，因此静香有可能受到前文的影响，以同一种口吻说话。此问题暂时以增加约束性提示词的方式修复，如果在使用中还是高强度地出现同一种说话模式，如解析网页链接和截图时一直以“啊，这不是xxx吗”起手的话，请及时反馈问题，或者使用自己的agent尝试解决问题后将问题描述和使用的修复方案一同上传到issue中，以进行更细致的调整。

### 话题设置

「更多设置」里有敏感话题模式，默认关闭，桌面和微信共用。开启后可回应非露骨的成人话题，不开放色情描写或未成年人性化内容；正常感情交流、健康知识、新闻和游戏讨论不因此一概屏蔽。详细范围在菜单里查看。

## 微信怎么用

绑定后直接发消息就能聊。可以发图后说「讲题」「翻译」，也可以引用某条文字、图片或文件继续问。明确引用会优先于最近材料；旧消息没缓存到或原文件已经不在时，需要重新发一下。

长回答可以分成几条发，有内容再补充。你中途接话，她会停止尚未发出的旧回复。微信连接页可以关闭「分条回复与补充」。

| 发给她的内容 | 用途 |
| --- | --- |
| `/帮助` | 查看可用指令 |
| `/图片`、`/附件` | 查看最近收到的材料编号 |
| `总结附件2`、`附件2第1-3页` | 指定文件或 PDF 页码 |
| `/待办 明天上午9点交报告` | 添加待办 |
| `10分钟后再提醒我` | 延后刚才那条提醒；不明确时会让你选 |
| `/电脑` 加具体要求 | 交给已配置的电脑文件助手处理 |
| `/停止`、`/状态`、`/结果` | 停止任务、查看状态或取回最近结果 |
| `/主动` | 查看主动搭话的设置方法 |

新收到的材料在电脑助手工作目录的「微信附件」里，按会话和日期存放，同名文件不会覆盖。微信连接页有「打开收到的附件」入口。

回复过程中会请求显示「正在输入」，包括分条之间的等待；具体是否显示、能保持多久，还要看手机微信的实际效果。当前没有接入原生语音条和视频消息，也没有把生成的文件直接回传微信。

### 主动搭话

默认关闭。可以在设置中心打开，也可以发 `/主动 开启`、`/主动 关闭`、`/主动 暂停`。想调整时间或频率，发 `/主动` 看帮助。

主要聊一些日常安排和兴趣，偶尔带一条有来源的新闻或提到以前的趣事。发过一条而你没回，就暂停后续闲聊，待办提醒照常。它仍在试用中，长期连接和实际说话效果还需要继续观察。

## 待办和番茄钟

直接说「提醒我明天9点开会」就能记待办，也可以在窗口里自己填。支持提前提醒、循环事项，以及桌面和微信提醒。说「做完了」时会尝试对应到具体事项，分不清就先让你选。

待办的快捷处理可以完成本次、延后提醒，或者开始关联专注。延后只影响这一轮，不改整个循环安排。

番茄钟还没开始时，点外面会收起面板；开始专注后，桌宠自动折叠，计时器保持置顶。退出再开可以恢复剩余时间，程序退出和电脑休眠的时间不计入专注。结束时由你选择继续、休息或完成待办。

聊天记录里的「通知」页会汇总待办、专注、研究进展和更新通知。开机列出错过事项的功能默认关闭，可在「设置中心 → 声音与提醒」开启。

## 外观和其他小功能

设置中心按聊天、主动搭话、声音与提醒、外观、连接与数据分组，可以直接搜索。常用开关在原来的齿轮菜单里也留着。

- **窗口背景**：普通功能页使用静香卡面，可以随机、固定一张，或者调整模糊和明暗。比例不同时按中心裁切。输入框和回复气泡使用单独的装饰框。
- **免打扰**：游戏或全屏时减少主动发言，并可自动折叠。你自己发起的聊天和设置的待办提醒不受影响。
- **剪贴板**：打开后会对新复制的文字、图片或网址作出回应，也可翻译外语。重复内容尽量不再说；剪贴板里的文字不会直接当成待办或文件指令执行。
- **天气、新闻和联网查询**：可以直接问。查不到、网页打不开时会说明情况；模型给出的解读仍可能出错。
- **使用时长**：可查看当天各程序的使用情况，也可以在聊天里询问。
- **提示音**：可选全部、待办和文件完成、仅待办或关闭，菜单里有试听。
- **运行状态与备份**：查看连接状态、重新连接微信、重试失败聊天；本地备份可按范围恢复，不包含模型密钥和微信绑定。

### 电脑文件助手

需要另外安装 Node.js 和 DSH（dsharness），并配置自己的模型账户。之后可以用 `/电脑` 提交具体任务，执行过程在窗口里显示，需要你回答的问题会回到聊天里。

工作目录和文件访问范围由你设置。微信端能否执行文件任务也有独立开关；普通聊天收到附件，不等于自动执行附件里的内容。

### 研究进展

在关注方向里输入内容后按回车，程序会查询文献，展示摘要和 DOI。可以让她讲某篇论文，也可以问「最近有什么新论文」。正文读不到时只能根据已读到的内容回答，不能代替自己看原文。

- **记忆同步（开发中）**：齿轮 →「双端共享记忆（开发中）」「立即同步记忆（开发中）」。双端同步还没做好，先和研究进展当初一样收起来了，点了只会说明情况；配对配置、journal、传输层代码都留着，开关是 `sync_runtime.SYNC_ENABLED`。当前共享字段的范围详见 `AI-DEVELOPMENT.md`。

## 语音和音乐

### 语音朗读

语音使用本地 GPT-SoVITS，需要单独安装和配置。没装时照常显示文字。检测不到安装目录的话，可以在「更多设置」里手动指定。

支持中文、日文朗读；选择日文时，屏幕仍显示中文。第一次开启需要等待模型加载，速度和显存占用取决于设备。「英文按英文念」可以单独开关，不出声时可先关掉排查。

参考音频随程序提供，训练好的喜多郁代音色权重在仓库的 `voice_model/`，来历和用法见 [音色说明](https://github.com/lxz61352-cmyk/shizuka-desktop-pet/blob/main/voice_model/说明.md)。没有单独训练静香的声音，选这个音色是因为两位角色都是长谷川育美配音。

权重通过 Git LFS 保存，普通程序压缩包不带这两份大文件。用 Git 获取时需要安装 Git LFS；下载后若只是几行文字的指针文件，就还没拿到实际模型。

### i wanna

菜单里点「播放 i wanna」，齿轮下面会出现旋转唱片。单击暂停或继续，长按三秒结束。

## 想自己改的话

源码是 Python + Tkinter + Pillow，Windows 包用 PyInstaller 构建。运行、测试和打包命令放在 [开发与验证](文档/开发与验证.md)，已有模块说明在 [AI-DEVELOPMENT.md](AI-DEVELOPMENT.md)。后者包含历史设计，具体以当前代码为准。

| 目录 | 放的东西 |
