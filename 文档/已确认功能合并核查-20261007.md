## 已恢复的原方案

| 功能 | 合并内容 |
| --- | --- |
| 待办按钮点击区域 | 保留原图外观，用最低非零透明度使整个矩形接收点击；缩放、隐藏重显后仍生效 |
| 设置保存 | 原子写入，失败记录错误并保留旧文件 |
| UI 队列 | 单轮最多 64 回调或约 5 毫秒，剩余任务按顺序继续 |
| 长记录上下文 | 减少全历史副本与中间对象，保留完整归档及消息配对 |
| 历史窗口 | 默认最近 300 条、加载更早记录、全历史搜索、旧记录修改更新 |
| 窗口通信 | 大历史页面分包，避免通信尺寸超限 |
| 聊天保存 | 紧凑 JSON，仍保留原子写入和旧数据兼容 |
| 通知与番茄钟 | 异常字段恢复、原文件备份、读写失败保护 |
| 后台取消和退出 | 停止 UI 回调、取消过时生成与语音等待、丢弃迟到音频，旧轮次不覆盖新状态 |

使用原工作目录的共同 Git 基线作三方合并，逐段检查差异；不是用旧 `pet.py` 整文件替换最新源码。20 个源码及测试文件无冲突合并。对已部署完整包的 Python 源码清单核查没有残留缺失模块；剩余差异对应本对话后续新增功能。

微信引用、连续消息打断、自然语言待办、记忆编辑、表情理解规则和喝水提醒保留。撤回了本轮临时提出的可见底板方案。
