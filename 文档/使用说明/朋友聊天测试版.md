# 静香 · 朋友聊天测试版

具体版本以窗口标题和导出 JSON 中的版本标记为准。当前已分发压缩包仍为 S2.3；源码候选为 S2.5，真实聊天效果尚未验证。

解压整个压缩包，双击 `ShizukaChatTest.exe`。请保留旁边的 `_internal` 文件夹，不要只拷贝 exe。无需安装 Python；只打开聊天窗口，没有桌宠、语音或后台主动消息。

## 开始聊天

1. 点击「连接设置」，填写测试发起人提供的接口、模型和**测试专用 key**。默认接口与当前项目的 DeepSeek Flash 配置一致。
2. 默认把 key 存入当前 Windows 用户的凭据管理器；取消勾选后只在本次窗口内使用。设置文件只保存接口、模型、接口类型。
3. 保存不会连接模型。输入消息后按 Enter 才发送；Shift+Enter 换行。失败不会自动重发。「停止」停止接收回复，但服务端可能已经开始生成。

软件包没有内置开发者的主密钥。保存在使用者电脑上的 key 无法保证使用者不能提取，请发起人提供单独可撤销、可限额的测试 key，不要分发主密钥。

聊天会发送到「连接设置」指定的模型服务。程序不向开发者自动上传聊天或反馈；聊天只在当前窗口内保留，关闭后不会自动恢复。设置保存在 `%LOCALAPPDATA%\ShizukaChatTest`，与桌宠分开。

## 测完怎么发回记录

1. 点击「写反馈」，记下想继续聊的地方，或哪里像盘问、说教、没接住话。
2. 点击「导出聊天记录」。常见联系方式、key、链接和文件路径会先自动遮盖。
3. 检查预览中的姓名、学校、地址等内容。可添加「额外隐私词」，也可直接编辑 JSON 正文、删除不想分享的消息；保留有效 JSON 格式即可。
4. 点击「已检查，保存 JSON」，选一个文件夹。文件名自动使用**保存时刻**，例如 `静香聊天_20260927_224512_123.json`；重复导出不会覆盖旧文件。
5. 自己把 JSON 发给测试发起人即可。软件不自动发送文件。

导出内容只有可见的用户/静香消息、反馈、完成状态、模型名称和版本标记；没有系统提示词、隐藏思考、接口 key、电脑用户名或本机路径。自动遮盖只能识别常见格式，保存前仍需本人检查正文。

## 这次主要测什么

自然聊天就好，重点看：她是否先回应你的内容；追问是否出于具体兴趣并让你愿意继续聊；说「记不清」「只是喜欢」「想休息」后是否能自然接住；提意见后是否能调整而不争辩。

这是候选角色卡测试版。它复用项目的角色卡编译、硬约束、交互理解与输出约定；不包含桌宠的任务、观察和长期记忆。因此结果用于判断**纯对话效果**，不代表完整桌宠功能的效果。
